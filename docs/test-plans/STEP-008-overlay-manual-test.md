# STEP-008 无插件透明覆盖层人工测试计划

## 1. 目标与边界

验证透明 Win32 覆盖层在完全禁用或移除 WoW 插件时仍能定位、交互和完成本地模拟聊天，并验证焦点隔离、鼠标穿透、前台门控、DPI、多显示器和安全链接行为。本计划不连接真实 Codex、模型或网络服务，不执行截图/画面识别，也不向 WoW 发送任何自动输入。

## 2. 环境记录

每轮记录：Windows build、WoW build、伴侣程序版本、WebView2 Runtime 版本、显示模式、显示器排列、每屏分辨率/DPI、HDR 状态、插件状态和测试时间。正式验收至少覆盖：

| 维度 | 最低范围 |
|---|---|
| 插件 | 未安装、禁用 |
| WoW 显示 | 窗口模式、窗口化全屏 |
| 分辨率 | 1920×1080、2560×1440、3840×2160 |
| Windows DPI | 100%、125%、150%、200% |
| 显示器 | 单屏、双屏、负坐标副屏、跨屏移动 |

## 3. 准备

1. 构建 Debug 伴侣程序并运行统一自动门禁。
2. 退出 WoW，临时移走或在角色选择界面禁用 `WowAIAssistant`；记录插件目录/加载列表证据，但不要提交含角色身份的截图。
3. 启动 WoW，使用窗口模式或窗口化全屏。
4. 启动 `wowai_companion.exe`；多客户端时从托盘明确选择目标客户端。

## 4. 用例

| 编号 | 操作 | 预期结果 |
|---|---|---|
| M-001 | 在插件未安装时选择 WoW 并激活游戏窗口 | 覆盖层显示在客户区右下区域；不要求锚点或插件面板 | 测试通过
| M-002 | 输入中英文问题，按 Enter 发送；Shift+Enter 换行；发送多条并滚动 | 用户消息出现，收到声明为本地模拟的确定性回复；滚动和换行正常，无联网 |  测试通过
| M-003 | 在 WoW 中手动打开聊天输入框，记下现有内容；点击覆盖层输入框并输入唯一字符串 | 覆盖层取得焦点；唯一字符串只出现在覆盖层，WoW 聊天框和快捷键状态不变化 |  测试通过
| M-004 | 点击“鼠标穿透”，再点击覆盖层原位置；从托盘恢复交互 | 穿透后覆盖层不截获鼠标；托盘可恢复交互；切换过程不向 WoW 合成键盘或鼠标事件 |  首轮发现底层 WoW 同一区域无法点击；修复跨进程命中穿透后于 2026-10-01 复测通过。伴侣小宠物形态作为后续产品建议保留，不纳入 STEP-008
| M-005 | Alt+Tab 到浏览器、桌面或其他应用，再返回 WoW | 离开 WoW 后覆盖层在 100 ms 轮询周期内隐藏；返回后重新出现，不覆盖其他应用 |  测试通过
| M-006 | 最小化、还原并退出 WoW | 最小化和退出后覆盖层隐藏；还原并重新选择/刷新后可恢复，无残留置顶窗口 |  测试通过
| M-007 | 移动、缩放 WoW 窗口并跨显示器 | 覆盖层持续位于所选客户区内，目标重定位延迟不超过 100 ms，无明显漂移 | 测试通过 
| M-008 | 依次执行 DPI/分辨率/双屏矩阵 | 覆盖层尺寸可用、客户区坐标正确，在负坐标显示器上不越界 |  测试通过
| M-009 | 开启 Windows 高对比度或提高文本缩放，使用 Tab 导航 | 文本可读，焦点轮廓清晰，输入/发送/穿透按钮可由键盘操作 | 测试通过
| M-010 | 点击内置“暴雪支持”链接 | 仅由玩家点击后交给系统浏览器；WebView 内部导航保持禁止；非白名单链接由自动测试覆盖并拒绝 | 测试通过
| M-011（可选、非阻塞） | 仅当游戏中已安装仓库当前版本插件时，启用插件并打开可信锚点，再关闭面板或禁用插件；不要为 STEP-008 专门覆盖旧插件 | 锚点存在时可使用增强内容区域；锚点消失后回退客户区相对布局，聊天不中断；未安装当前插件时记录 `N/A：未更新可选插件` |
| M-012（开发者隔离测试、非阻塞） | 由开发者或 CI 在独立进程环境中覆盖 WebView2 Runtime 查找路径；禁止卸载、损坏或全局禁用系统 WebView2 Runtime | 主程序给出可操作的 Runtime 修复提示，不显示不完整覆盖层、不崩溃；普通人工验收记录 `N/A：需隔离环境` |

## 5. 通过条件

- STEP-008 核心门禁为 M-001 至 M-010 全部通过，且 M-003 必须有明确的“WoW 未收到字符/快捷键”记录。
- M-011 属于可选插件增强回归，不安装仓库当前插件时记录 N/A，不阻塞无插件覆盖层验收。
- M-012 属于开发者/CI 隔离环境负向测试，普通人工验收记录 N/A；不得要求测试者卸载或全局禁用系统 WebView2 Runtime。
- 插件未安装和禁用两条路径都完成 M-001、M-002、M-005、M-006。
- DPI/多屏矩阵无覆盖其他应用、越出客户区或失焦残留。
- 进程退出后无 `wowai_companion.exe` 和置顶覆盖层残留。
- 失败项记录实际结果、复现频率、显示环境和修复后复测结论；不提交私人聊天或角色身份截图。
