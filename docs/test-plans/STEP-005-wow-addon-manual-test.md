# STEP-005 WoW 插件人工测试计划

> 历史证据：本计划验证的是 2026-09-29 的插件内聊天壳 PoC。ADR-016 接受后，消息输入、发送按钮和伴侣离线状态已删除；不得再把本计划作为当前插件验收标准。

## 测试边界

只通过玩家手动输入命令、拖动和点击验证 UI；不得使用自动化输入、宏循环或任何方式控制角色。
测试账号不得记录到仓库，截图和聊天内容不作为测试产物提交。

## 前置步骤

1. 将 `addon/WowAIAssistant` 复制到正式服 `_retail_/Interface/AddOns/`。
2. 在角色选择界面确认插件已启用且未被标为不兼容。
3. 登录后执行 `/console scriptErrors 1`，随后 `/reload`。
4. 不启动伴侣程序；STEP-005 必须验证独立降级路径。
