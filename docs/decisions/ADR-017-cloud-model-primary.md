# ADR-017：普通玩家路径采用显式同意的云端模型

- 状态：已接受（2026-10-02）
- 日期：2026-10-02
- 负责人：项目负责人
- 决策截止点：STEP-012 云端视觉改造
- 关联：CHAT、CONTEXT-01 至 CONTEXT-12、D-04、D-08、D-09、E-10 至 E-14、H-03、H-05
- 取代：ADR-010 作为产品默认提供方的决定

2026-10-02 修订：ADR-018 保留本 ADR 的“云端主路径、逐图同意、持续观察本地隔离”结论，
但取代 `openai` 作为唯一产品 provider 的细节；首个联调目标改为 DeepSeek。

## 背景

普通 WoW 玩家电脑主要资源已经由游戏、插件、录屏/语音和其他桌面程序占用。要求玩家额外
安装、下载、配置并长期运行本地文本或视觉大模型，会引入显存、内存、磁盘、功耗、首次下载、
模型兼容性和故障排查门槛，不能作为大众产品的正常前提。STEP-011 的 Ollama 实现证明了提供方
抽象，但真实模型验收未完成，也不应继续决定产品主线。

## 决策

1. 面向普通玩家的默认路径是玩家明确启用的受控云端模型；产品不得要求本地模型。具体 provider
   由 ADR-018 的注册表管理。
2. 所有文字问题都会清楚标识云端处理。配置必须包含精确模型、上传总开关和可用凭据；缺一项
   即失败关闭，不回退到其他提供方。
3. 截图继续在本机完成窗口限定、裁剪、隐私遮挡、有效性检测、缩放、编码和预览。只有玩家对
   当前预览逐次点击确认，才可上传一张图片。
4. 每张图片请求记录与当前 provider 匹配的上传目标、用途 `visual-question`、确认时间和提示版本；未确认图片
   不能进入 Host、App Server 或网络。
5. 默认关闭的场景感知继续使用轻量本地规则。持续观察的原始帧和 `screen-observed` 派生摘要
   不自动发送到云端；需要更强视觉理解时，玩家重新走单张截图确认流程。
6. 玩家明确开启的插件桥仍只产生 `plugin-public` 结构化公开上下文；它可以随问题提交，但不是
   截图确认的替代品，也没有返回游戏的通道。
7. M0 开发期允许从进程环境读取 `OPENAI_API_KEY`，但不得记录、回显或持久化。正式产品必须在
   STEP-020 迁移到 Windows Credential Manager/DPAPI；环境变量不是发布形态。
8. Ollama 适配器保留为非核心实验和回归夹具，不提供安装、下载或自动选择，不纳入普通玩家验收。

## 隐私与费用边界

- UI 在截图确认前显示提供方、上传用途及一次性同意含义。
- 图片只保留一份应用拥有的临时文件，用于锁定 App Server 的 `localImage` 输入；请求结束即删，
  异常退出残留在下次启动清理。
- 持续画面观察不形成云端视频流，也不自动升级为逐帧模型调用。
- 云端图片会产生模型用量；后续用量上限、费用提示和防重复提交属于 STEP-021 放行条件。
- 依据官方 OpenAI 数据控制说明，提交的图片输入会经过安全扫描，特定命中情况下可能被保留；
  产品提示不得把“临时本地文件已删除”描述成“云端绝不保留”。

## 验证条件

- 未配置提供方、精确模型、总开关或凭据时，云端路径失败关闭。
- 未确认图片不能进入 Host/App Server；确认后请求包含目标、用途、时间和提示版本。
- 云端请求使用锁定 Codex App Server，命令、文件写入、MCP、浏览器、计算机控制及审批继续拒绝。
- 成功、失败、取消和重启清理临时图片；日志不含密钥、Authorization header 或图片 Base64。
- 场景/教学观察运行时没有周期性图片上传，`screen-observed` 摘要不自动进入云端请求。
- 普通玩家测试矩阵不安装 Ollama 或其他本地大模型。

## 回退方案

如果云端成本、隐私、可用性或政策无法满足发布门禁，则回退为文字和插件公开上下文工具，并
保留玩家主动截图的本地预览，但不上传图片；不得通过恢复本地大模型硬件要求来绕过产品决策。

## 依据

- [OpenAI Images and vision](https://developers.openai.com/api/docs/guides/images-vision)：Responses API 支持图片输入，图片计入模型用量。
- [OpenAI Data controls](https://developers.openai.com/api/docs/guides/your-data)：图片/文件输入受平台安全扫描与适用的数据保留规则约束。
