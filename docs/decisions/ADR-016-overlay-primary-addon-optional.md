# ADR-016：覆盖层为主交互入口，插件为可选上下文源

- 状态：已接受（产品方向）
- 日期：2026-10-01
- 负责人：项目负责人
- 决策截止点：STEP-008 开始前
- 关联：CHAT-01 至 CHAT-11、CONTEXT-01 至 CONTEXT-12、ADDON-01 至 ADDON-10、ACH-07、ACH-08、COACH-01 至 COACH-11、B、C、D、G

## 背景

WoW Lua 插件运行在受限沙箱中，不能与本地伴侣程序建立常规实时 IPC。把聊天输入、模型流式回复或伴侣在线状态设计成“插件能力”，会形成无法实现或只能依赖脆弱规避方案的产品承诺。

项目已经具备 Windows 伴侣程序、WoW 窗口发现、只读客户区捕获和视觉锚点 PoC，因此实时聊天可以完全由独立桌面覆盖层承担。插件仍有价值，但它的职责必须与本地实时会话解耦。

## 决策

1. Windows 透明覆盖层是聊天、流式回复、错误、设置和截图发送授权的唯一实时交互入口。
2. 覆盖层通过快捷键或系统托盘独立打开，并以 WoW 客户区为定位基准；没有插件时核心功能仍须完整可用。
3. WoW 插件降级为可选增强组件，只提供：
   - 可见视觉锚点，用于提高覆盖层定位精度；
   - 玩家明确打开的公开上下文卡片；
   - 玩家明确开启的单向视觉数据桥；
   - 插件自身设置和状态说明。
4. 插件可提供由玩家明确开启、持续可见并带状态标签的单向视觉数据桥。桥接像素可以机器编码，但必须同时提供人类可读的字段预览；伴侣程序只能读取，不能返回指令。
5. 不把 SavedVariables 当作运行时 IPC。未来如支持导入，只允许在 WoW 未运行或文件已稳定时由玩家明确触发，并把数据标记为延迟快照。
6. 画面理解分两级：
   - P0 按需截图：逐次由玩家附加、预览，并以点击“发送”授权本次上传；
   - P1 场景感知：默认关闭，仅在 WoW 前台、明确指示开启时对最小区域进行低频本地粗分类，原始帧不落盘、不默认上传。
7. 无论输入来自画面还是插件公开上下文，系统都不得生成实时战斗指挥，不得向 WoW 注入或模拟任何输入。
8. 数据桥允许发布用于教学的低频构筑快照，以及 API 明确公开且非 secret value 的实时上下文。战斗中可继续发布遭遇、追踪成就、公开条件进度、明确成功/失败状态和允许读取的玩家事件；是否允许由字段级来源与 secret-value 检查决定，而不是按战斗状态一刀切。
9. 数据桥采用事件驱动并在 100 毫秒窗口内合并事件，首期最高每秒更新 10 次、单帧载荷不超过 512 字节。帧包含版本、字段位图、字段来源、序号、长度与 CRC；任何未知、损坏、重复或超频帧都失败关闭。
10. 插件不得尝试转换、字符串化、比较、推导或通过数据条导出 secret values。这个限制只约束插件结构化数据源，不把“secret”直接当作产品功能开关。
11. 伴侣程序可在玩家明确开启的教学会话中，对所选 WoW 客户区内全部实际可见像素进行本地画面观察，包括游戏世界、原生 UI、插件 UI、聊天、动作条、冷却动画、资源条、系统警告和成就提示，并生成带来源、理由与置信度的异步建议。画面观察不得扩大到其他窗口、伪装成插件数据或产生任何游戏输入。
12. 实战教学不是硬实时控制环，不承诺逐帧或瞬时回复。但系统不得依赖当前模型较慢来证明安全；即使未来模型更快，显式会话、零输入、窗口范围和来源标记仍是硬边界。

## 结果

### 正面结果

- 实时聊天不再依赖 WoW 插件沙箱不具备的通信能力。
- 覆盖层、模型和网络故障不会破坏插件或游戏客户端。
- 插件安装成为可选项，首次使用路径更短。
- 插件能提供比 OCR 更可靠、更低延迟的结构化公开上下文，同时保持来源对玩家可见、可预览、可关闭。
- 新手不必逐个描述技能；AI 可以基于实际构筑解释核心资源、技能联动、输出优先级和练习方法。
- 即使普通插件字段在战斗中变为 secret，只要相应信息仍然呈现在玩家屏幕上，教学模式仍可将其作为不确定的画面观察，而不是让助手完全失明。

### 代价

- 覆盖层必须独立解决焦点、DPI、多显示器、窗口前台判断和自动隐藏。
- 画面识别只能给出带置信度的观察结果，不能等同于插件结构化数据。
- 单向视觉数据桥增加协议、跨 DPI 解码、刷新限流和字段审计成本；插件桥不承载 secret values，屏幕可见战斗信息由独立的本地画面观察路径处理。
- 外部覆盖层和屏幕感知仍需在每次发布前按最新暴雪条款进行合规复审。
- 对屏幕可见战斗 UI 的理解可能仍被暴雪视为规避其战斗插件设计意图；“面向新手”和“没有自动输入”支持产品的非自动化定位，但不能单独证明机制已获允许。

## 合规依据与限制

本决策以 2026-10-01 可访问的暴雪公开文件为风险边界依据，包括 [Blizzard End User License Agreement](https://www.blizzard.com/en-us/legal/bfbbb648-bcc6-4b78-a5c7-e2fe20c135df/blizzard-end-user-license-agreement)、[Anti-Cheating Agreement](https://www.blizzard.com/en-us/legal/cd5930c0-2784-420c-a23d-1e0d6ff8599b/anti-cheating-agreement)、[World of Warcraft User Interface Add-On Development Policy](https://us.forums.blizzard.com/en/wow/t/ui-add-on-development-policy/24534)、[How Midnight’s Upcoming Game Changes Will Impact Combat Addons](https://news.blizzard.com/en-us/article/24244638/how-midnights-upcoming-game-changes-will-impact-combat-addons) 与 [Combat Philosophy and Addon Disarmament in Midnight](https://news.blizzard.com/en-gb/article/24246290/combat-philosophy-and-addon-disarmament-in-midnight)。暴雪明确区分 UI 展示与由插件分析实时战斗信息并替玩家作决策，因此本项目允许构筑感知和教学解释，但坚持零输入注入、零内存读取、零封包分析、零 secret-value 绕过和无隐藏插件通道。

公开条款并未构成暴雪对本产品或任意外部覆盖层的预先批准。本 ADR 是保守工程边界，不是法律意见或合规保证；发布前仍需重新审查当时有效条款，必要时寻求暴雪书面澄清。

## 禁止的替代方案

- 由外部程序向游戏窗口发送按键、鼠标或窗口消息来传递问题或命令；
- 通过聊天频道、宏、剪贴板自动粘贴或输入广播建立通信；
- 隐藏、无状态标识、不可关闭或超过协议频率上限的像素/颜色编码；
- 转换、字符串化、比较、推导或通过视觉旁路导出 secret values、受保护值或来源不明值；
- 把任何实战建议自动转换为技能、宏、目标、打断、移动或其他游戏输入；
- 在用户未开启教学会话、无持续状态指示或 WoW 非前台时观察战斗 UI；
- 运行中修改 SavedVariables 并强制插件重载；
- 注入、Hook、读取游戏内存或分析网络封包。

## 验证条件

- 完全移除插件后，覆盖层仍能打开、聊天、截图提问和显示回复。
- WoW 失去前台、最小化或退出后，覆盖层隐藏且捕获停止。
- 覆盖层输入焦点下的字符不会进入 WoW。
- 视觉数据桥仅在玩家开启时可被读取，状态、字段预览与数据来源可见；普通战斗成就字段可以传输，secret/受保护/未知字段被拒绝；协议损坏、超频或读取失败时安全降级。
- 实战教学默认关闭；开启后每条建议显示 `screen-observed` 等来源、观察时间、置信度和解释，关闭/失焦后立即停止且无任何游戏输入。
- 捕获、临时数据、日志和云端提交满足 PRD 的知情、最小化与清理要求。

## 回退方案

如果透明覆盖层的兼容性或合规风险不可接受，回退为普通桌面侧边窗口；保留只读、玩家主动截图和可选插件上下文，但不通过注入、输入模拟或其他规避方式维持“游戏内”外观。
