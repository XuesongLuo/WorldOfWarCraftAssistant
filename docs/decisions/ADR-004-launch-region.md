# ADR-004：首发区域

- 状态：已接受（2026-10-04）
- 日期：2026-09-28；2026-10-04 接受
- 负责人：项目负责人
- 决策截止点：STEP-014 开始前（M0 期间完成选择）
- 关联：F-01 至 F-09

## 背景

国服和国际服在内容版本、术语、本地化、角色服务和资料来源方面可能不同。首发区域会影响知识数据、黄金问题集和合规审查。

## 决策

M1 以国服正式服和简体中文为首发用户体验。正式服玩法知识使用一套以稳定 ID、游戏
版本和补丁号为主键的标准内容模型，不预设国服与国际服存在两套职业、技能、任务或物品规则，
也不复制建设两套知识库。

`region` 保留为服务和本地化覆盖层，只用于：

- 选择账号、鉴权、API endpoint 和可用服务；
- 中文术语、运营活动、开放时间、商店/支付和客服信息；
- 对已有官方证据的实际区域例外做窄化覆盖。

不会为了理论上的区域差异让所有知识条目强制分叉；只有找到官方差异证据时才新增覆盖。

本地索引/缓存的目标不是让 WoW 在断网时可玩，而是固定资料版本、提供可重现回答，并在资料源
或单一 AI 服务临时不可用时安全降级。不建设“断开全部网络仍可进行 WoW 问答”的产品验收项。

## 未选方案

1. 国际服优先。
2. 把正式服核心内容按区域复制为两套数据。
3. 双区域同时做完整服务、运营与本地化验收。

## 验证与接受条件

- 项目负责人已明确国服正式服优先，且核心玩法知识不按区域复制。
- 选定区域的资料来源、许可证、版本标记和术语表可建立。
- 黄金问题集能区分区域和版本，不把跨区信息混为确定结论。

## 回退方案

若区域资料授权或版本质量无法在 M1 达标，MVP 降级为不依赖区域知识库的技术演示，不对外发布内容问答能力。
