# ADR-004：首发区域

- 状态：草案，待项目负责人选择
- 日期：2026-09-28
- 负责人：项目负责人
- 决策截止点：STEP-014 开始前（M0 期间完成选择）
- 关联：F-01 至 F-09

## 背景

国服和国际服在内容版本、术语、本地化、角色服务和资料来源方面可能不同。首发区域会影响知识数据、黄金问题集和合规审查。

## 默认 PoC 假设

M0 不接入区域性在线资料，只验证简体中文 UI 和本地技术闭环。为避免过早扩大资料与测试范围，进入 M1 时默认先按国服正式服设计数据过滤字段，同时保证契约包含 `region`、`locale` 和游戏版本，保留国际服扩展能力。

## 候选方案

1. 国服优先（默认 PoC 假设）。
2. 国际服优先。
3. 双区域同时首发：覆盖面最大，但资料授权和测试成本最高。

## 验证与接受条件

- 项目负责人明确首发区域及不支持范围。
- 选定区域的资料来源、许可证、版本标记和术语表可建立。
- 黄金问题集能区分区域和版本，不把跨区信息混为确定结论。

## 回退方案

若区域资料授权或版本质量无法在 M1 达标，MVP 降级为不依赖区域知识库的技术演示，不对外发布内容问答能力。
